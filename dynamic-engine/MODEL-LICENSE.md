# English → Chinese translation model

This distribution includes the unmodified Argos package `translate-en_zh-1_9.argosmodel`.

- Authors: Jörg Tiedemann and Santhosh Thottingal.
- Title: “OPUS-MT — Building open translation services for the World”.
- Venue: Proceedings of the 22nd Annual Conference of the European Association for Machine Translation (EAMT), Lisbon, Portugal, 2020.
- Original OPUS model license: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/), as stated in the README included in the model archive.
- Package source: [Argos Open Tech model repository](https://data.argosopentech.com/argospm/v1/translate-en_zh-1_9.argosmodel).
- SHA-256: `433e7c4f034d87fbe2353161e05f18646d7999452f801a4e1f0378522b9850ab`.

The package is not modified. This tool uses CTranslate2 and SentencePiece to run the model locally. Their licenses remain in the Python packages installed by the setup script.

When a Microsoft Chinese language pack is already installed, the installer can read its local MIT-licensed message translations. Those installed language-pack files and their license are not bundled in the portable ZIP.
